## 怎么用

1. 连上你要测的节点，并确认走的是代理（规则模式下先临时切到全局）。
2. 在命令行对你常用服务的域名执行 ping，测 100 次左右。
3. 把整段输出粘贴到上面，点“计算”。
4. 换到晚高峰（约 19:00–23:00）再测一组，几天后对比。

## 结果怎么读

- **丢包率**：超时的行占总样本的比例。持续偏高会先影响视频通话与游戏。
- **最小 / 平均 / 中位数 / 最大**：看分布，不要只看平均数。
- **抖动**：相邻两次延迟之差的平均绝对值，越小越稳。
- 结果只代表你的网络、你的时段。
