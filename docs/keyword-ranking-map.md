**追踪频率**：不逐日重复搜索，建议每 1-2 周更新一次本表（除非有重大页面改版需要立即验证效果）。

**已知工具限制**：本站没有 Bing Webmaster Tools 的登录权限，无法拿到精确的数字排名（第几名）。以下"Bing 现状"列基于人工浏览器 SERP 抽查——只能判断"是否进入可见的前 10 条结果"，无法判断具体是 Top 20/50/100 中的第几名。如果你愿意开通 Bing Webmaster Tools 并分享 Search Performance 截图/导出数据，可以把这张表升级为有精确名次的版本。

**已知工具风险**：浏览器 SERP 抽查偶尔会返回与查询完全无关的内容（本轮"性价比机场"连续 3 种措辞都返回无关内容：Naver 门户、hate 反义词词典、ChatGPT/OpenAI）。遇到这种情况会标注"本轮异常，未采信"，不会把无关结果当成真实竞争格局，也不会反复重试浪费执行时间。
