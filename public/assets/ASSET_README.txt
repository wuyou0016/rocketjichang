ROCKETJICHANG UI ASSET PACK
=============================

Purpose:
Production-ready visual assets for the Rocket Airport homepage reference UI.

Rules:
- Reference these files directly from /public/assets/...
- Preserve aspect ratio.
- Do NOT use object-fit: cover.
- Do NOT distort, redraw, or replace with emoji/CSS drawings.
- Position with CSS only.
- Dark/Light nebula files are full-canvas backgrounds.
- Transparent assets are intended for absolute positioning.
