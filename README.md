## 💻 2026 客户端核心优化指南
- **TUN 虚拟网卡**：在 Clash Verge 或 Sing-box 中开启服务模式与 TUN 模式，确保全系统各软件无死角走代理流量。
- **DNS 泄露防护**：推荐配置阿里与腾讯 DoH（国内解析）配合 Cloudflare 1.1.1.1 DoH（海外解析），消除 DNS 污染。
